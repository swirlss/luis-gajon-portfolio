# Luis Gajon — Free Portfolio Website

This is a static HTML/CSS/JavaScript portfolio. It needs no paid hosting or backend.

## Free publishing with GitHub Pages

1. Create a free account at GitHub if you don't already have one.
2. Create a new repository named `luisgajon.github.io` (replace with your GitHub username if different).
3. Upload `index.html`, `style.css`, and `script.js`.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main`, and choose `/ (root)`.
6. Save. Your site will be available at `https://YOUR-USERNAME.github.io/`.

## Before publishing

- Replace the LinkedIn placeholder in `index.html` with your real LinkedIn URL.
- Add your PDF resume later (for example `resume.pdf`) and change the site button to link to it.
- Add project screenshots when ready.
- Consider using a custom domain later if you want one; GitHub Pages itself can remain free.
